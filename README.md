# Task Manager App

A clean and modern task management web application built with HTML, CSS, and JavaScript.

## About
This app allows users to add, complete, and clear tasks. 
It tracks the total number of tasks, pending tasks, and completed tasks in real time.

## Built With
- HTML
- CSS
- JavaScript

## Features
- Add new tasks
- Mark tasks as complete
- Clear all tasks
- Live task counter showing Pending, Done and Total
- Responsive design for both desktop and mobile
